# Referências de Design - EduTrack AI

Durante a pesquisa por referências visuais e estruturais no Figma Community, selecionei dois templates que apresentam soluções interessantes para o dashboard do EduTrack AI:

## 1. Educational Dashboard (Visão do Aluno)
* **Link:** [Figma - Educational Dashboard (Community)](https://www.figma.com/design/j1Z8lOqEnxc9iI1qyKxryb/Educational-Dashboard--Community-?node-id=2-2513&p=f&t=QOyXAwyqoR8zYl3p-0)
* **Por que é útil:** Este template (especialmente na versão Dark Mode) tem uma organização excelente para a página inicial de um estudante. Gostei muito da forma como as "Upcoming Activities" (Próximas Atividades) são listadas de forma clara com datas em destaque. Além disso, o painel lateral de navegação é limpo e direto, algo que podemos usar para transitar entre matérias, notas e faltas.

## 2. Educational Dashboard (Visão do Professor/Administrador)
* **Link:** [Figma - Educational Dashboard (Teachers)](https://www.figma.com/design/POsaRoK6KHv1nYoYP1Rthn/Educational-Dashboard--Teachers---Community-?node-id=1-1532&p=f&t=SKGKv01WAgjiQDhz-0)
* **Por que é útil:** Embora seja focado na visão do professor, a estrutura de UI para exibir dados estatísticos é perfeita para o nosso projeto. Os blocos de estatísticas e o gráfico de "Attendance" (Frequência) podem ser facilmente adaptados para o EduTrack AI para mostrar a evolução das notas e o controle de faltas do próprio aluno ao longo do semestre. O aproveitamento dessa organização de interface nos poupará muito tempo.
